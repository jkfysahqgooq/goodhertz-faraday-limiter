## Overview

Goodhertz Faraday Limiter is a clean brick-wall limiter with an intelligent program-dependent release algorithm that preserves transient punch while taming peak levels.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Goodhertz Faraday Limiter** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Brick Wall** | True brick-wall limiting with zero overshoot above the ceiling |
| **Auto Release** | Program-dependent release automatically adjusts to signal density |
| **True Peak** | True peak mode prevents intersample overs for streaming delivery |
| **Stereo Link** | Switchable linked and unlinked stereo modes for different sources |
